Overview

This project aims to automatically colorize the Prokudin-Gorskii glass plate images by aligning the three color channels (B, G, R) and applying various image enhancement techniques. The goal is to produce color images with minimal visual artifacts.

Approach

Alignment Metrics

I implemented and compared two similarity metrics for aligning the color channels:

1. SSD (Sum of Squared Differences) / L2 Norm

SSD measures the pixel-wise differences between two images. It computes the sum of squared differences across all pixels:

SSD = Σ(x,y) (image1(x,y) - image2(x,y))²

How it works: For each possible shift (dx, dy), I compute the SSD between the shifted channel and the reference channel. The shift with the minimum SSD represents the best alignment.

2. NCC (Normalized Cross-Correlation)

NCC measures the similarity between two images by computing the dot product of normalized image vectors. As described in the assignment, this is:

NCC = (image1 / ||image1||) · (image2 / ||image2||)

In my implementation, I use the statistically normalized version (Pearson correlation), which is mathematically equivalent:

NCC = Σ [(img1 - μ₁)/σ₁] × [(img2 - μ₂)/σ₂]
where μ is mean, σ is standard deviation

How it works: For each possible shift, I normalize both images by subtracting their mean and dividing by their standard deviation. This removes brightness and contrast differences, leaving only structural information. I then compute the dot product of these normalized vectors. The shift with the maximum NCC represents the best alignment.

Implementation Details

  • Simple Alignment: Exhaustive search over a [-15, 15] pixel window using SSD metric
  • Pyramid Alignment: Coarse-to-fine multi-scale alignment using SSD metric
  • Simple Alignment: Exhaustive Search with NCC: More robust to brightness differences
  • Pyramid Alignment: Coarse-to-fine multi-scale alignment using NCC metric.
  • Split images into three equal thirds (B, G, R channels)
  • Align G and R channels to B channel (reference)
  • Use np.roll() for efficient image shifting
  • Crop 20-pixel borders before computing alignment metrics

Bells & Whistles

1. Better Features: Edge-Based Alignment

The emir.tif image is known for having extreme brightness differences between channels (bright blue robes in blue channel, dark in red channel). My implementation automatically applies edge-based features to this image even in the "basic" configurations to ensure successful alignment.

Problem: Basic SSD alignment fails on emir.tif because the color channels have very different brightness values, leading to poor pixel-wise matches.

Solution: By using edge-detected versions of the images (Sobel filter), the alignment focuses on structural features rather than raw pixel intensities, allowing successful alignment.

2. Normalized Cross-Correlation (NCC)

NCC is more robust to brightness differences than SSD. I implemented both metrics and found NCC generally performs better, especially when combined with edge features.

Problem: The church.tif image fails with basic SSD because the three color channels have very different brightness values due to the colored architecture and blue sky.

Solution: By switching from SSD to Normalized Cross-Correlation (NCC), the alignment succeeds because NCC normalizes out brightness differences and focuses on structural correlation.

Church with SSD
Church with NCC

3. Automatic Border Cropping

The aligned images have colored borders where channels don't overlap perfectly. I implemented automatic border detection using edge detection to find where the actual image content begins.

4. Automatic Contrast Enhancement

Rescales intensities so the darkest pixel maps to 0 and the brightest to 255. Uses percentiles to be robust to outliers.

5. Automatic White Balance

Corrects color casts using the "gray world" assumption - that the average color in the image should be neutral gray. This produces more natural-looking colors.
